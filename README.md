# CellWeave: Reconstructing Cells in Visium HD by Weaving Spatial Transcriptomics and Morphology


## Overview

Visium HD profiles transcriptomes at 2 μm resolution but lacks explicit cell boundaries. Here we present CellWeave, a multimodal graph framework that reconstructs cells from histological images and bin-level gene expression. CellWeave learns cellular co-membership between neighboring bins using nucleus-derived supervision, adaptively fuses morphology and transcriptomics through a mixture-of-experts module, and assembles cell instances by seed-guided graph partitioning. To address the lack of manually annotated cell boundaries in native Visium HD data, we establish a multi-perspective evaluation framework combining reference-based geometric evaluation, transcriptomic consistency and relative agreement analysis, and further introduce a Xenium-derived simulated Visium HD benchmark with cell-boundary labels for direct quantitative assessment. Across mouse brain and human cancer datasets, CellWeave improves segmentation on simulated benchmarks and agreement with 10x Genomics-provided reference segmentations. CellWeave enables robust cell-resolved reconstruction from high-resolution spatial transcriptomics, supporting downstream analyses including fine-grained cell annotation, spatial organization and tissue microenvironment characterization.

```bash
git clone https://github.com/liiilongyi/CellWeave
cd CellWeave

conda create -n cellweave python=3.10

pip install -r requirements.txt
```

## Pretrained Models

The pretrained weights for UNI and scGPT are not included in this repository because of their large file sizes and licensing restrictions. Please download them manually and place them in the paths shown below.

### UNI Foundation Model

Request access and download the official UNI checkpoint from:

https://huggingface.co/MahmoodLab/UNI

After downloading, place `pytorch_model.bin` at:

```text
CellWeave/
└── UNI/
    └── checkpoints/
        └── uni/
            └── pytorch_model.bin
```

### scGPT Pretrained Model

Download the scGPT pretrained model from:

https://drive.google.com/drive/folders/1oWh_-ZRdhtoGQ2Fw24HP41FgLoomVo-y

Place the downloaded model folder at:

```text
CellWeave/
└── scGPT/
    └── pretrained/
        └── scGPT_human/
```

The `scGPT_human` folder should contain the pretrained scGPT files, including the model checkpoint and vocabulary files.

## Input Data

CellWeave requires the standard 10x Visium HD output files and an H&E image.

Place the 10x Visium HD `binned_outputs` folder in the project root:

```text
CellWeave/
└── binned_outputs/
    └── square_002um/
        ├── filtered_feature_bc_matrix.h5
        ├── raw_feature_bc_matrix.h5
        └── spatial/
            └── tissue_positions.parquet
```

The H&E whole-slide image should be decoded from the original 10x Visium HD BTF file, for example using QuPath, and saved as a PNG file under:

```text
CellWeave/
└── UNI/
    └── <your_HE_image>.png
```

## Configuration

Before running the pipeline, edit the configuration dictionary near the beginning of `CellWeave.py`.

Five parameters need to be set:

```python
self.config = {
    "SAMPLE_ID": "mouse_brain",
    "IMAGE_PATH": "UNI/mouse_brain_demo.png",
    "POS_PATH": "binned_outputs/square_002um/spatial/tissue_positions.parquet",
    "EXPR_FILTERED_H5": "binned_outputs/square_002um/filtered_feature_bc_matrix.h5",
    "EXPR_RAW_H5": "binned_outputs/square_002um/raw_feature_bc_matrix.h5"
}
```

- `SAMPLE_ID`: a user-defined sample name. Output files generated by the pipeline will include this ID.
- `IMAGE_PATH`: path to the decoded H&E image file.
- `POS_PATH`: path to `tissue_positions.parquet` from the 10x Visium HD `binned_outputs` directory.
- `EXPR_FILTERED_H5`: path to `filtered_feature_bc_matrix.h5`.
- `EXPR_RAW_H5`: path to `raw_feature_bc_matrix.h5`.

## Usage

Run CellWeave from the project root:

```bash
python CellWeave.py
```

The graphical interface will launch and provide step-by-step execution buttons as well as an automatic full-pipeline option.

To run the complete workflow, click:

```text
Run Entire Pipeline Automatically
```

The pipeline includes preprocessing, scGPT transcriptomic encoding, UNI morphology feature extraction, StarDist nucleus detection, seed and label generation, graph neural network training, and final cell diffusion.

## Output

After the full pipeline finishes, the final cell reconstruction result is saved in:

```text
{SAMPLE_ID}_seed.h5ad
```

The reconstructed cell assignment information is stored in the `obs` field of this AnnData file and can be used for downstream cell-level spatial transcriptomics analysis.
